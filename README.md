# imtoken-puffer


这是一款兼容 imToken 的 Puffer 质押 Mini App，支持连接 imToken 钱包（基于 Token Core），可将 ETH / stETH / wstETH 质押铸造 pufETH。

核心功能：
- 钱包连接与实时余额显示（ETH + pufETH）
- 当前汇率（rate）展示
- 支持 ETH 真实质押铸造 pufETH（其他资产模拟演示）
- UniFi Vault 机会展示与引导
- DEX 聚合器一键存入演示（任意代币 → pufETH 一站式流程）

作品强调安全自托管、用户友好引导，完全在 imToken 浏览器中运行，适合普通用户快速参与 Puffer 质押。使用 AI 辅助开发，界面简洁清晰。
